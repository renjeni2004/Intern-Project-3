🚀 Completed my Task 3 project: Customer Churn Prediction System using Machine Learning!

As part of my Data Science & Data Analytics using Python internship, I developed an end-to-end machine learning workflow to predict customer churn and explore customer segments.

🔍 What I implemented:
• Data cleaning, exploratory data analysis and feature engineering
• Data preprocessing using imputation, scaling and one-hot encoding
• Logistic Regression and Random Forest model comparison
• Stratified cross-validation and hyperparameter tuning
• Model evaluation using Accuracy, Precision, Recall, F1-score and ROC-AUC
• Confusion matrix, ROC curve and permutation feature importance
• K-Means customer segmentation
• Model persistence using Joblib
• Interactive prediction interface using Streamlit

🛠️ Tech stack:
Python | Pandas | NumPy | Scikit-learn | Matplotlib | Seaborn | Streamlit | Joblib | Git

📌 Key learning:
This project helped me understand the complete machine learning lifecycle — from preprocessing and model selection to evaluation, persistence and application development.

⚠️ Dataset transparency: The included dataset is synthetic and was generated for educational demonstration. The reported evaluation metrics should not be interpreted as real-world customer churn performance.
